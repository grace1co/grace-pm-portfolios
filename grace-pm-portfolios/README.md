# Grace Okoro — PM Portfolio Collection

Static HTML portfolios for direct sharing with recruiters.

## Directory structure

- `general-project-management/index.html` — general PM portfolio, source: `original.html`
- `pharmacists-mutual/index.html` — tailored Pharmacists Mutual case studies, source: `pharmacistsmutual(1).html`
- `index.html` — neutral root landing page

## Publish with Cloudflare Pages

Connect this repository to Cloudflare Pages with production branch `main`, framework preset `None`, no build command, and build output directory `.`. Each folder with an `index.html` is accessible at `/<folder-name>/`.

Replace an individual `index.html` file and commit to automatically publish the updated page.

Note: static sites are publicly accessible to anyone with the link; the GitHub repository can remain private. Some linked images in the general portfolio are externally hosted and may depend on third-party availability.
